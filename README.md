# 🧳 Travelgram - Perfil de Viagens

## 🌟 Sobre o Projeto  
Perfil de viagens desenvolvido como exercício do curso de Full Stack da Rocketseat, focando em fundamentos de HTML e CSS com design moderno e focado em experiências de viagem.

- 🎨 Design limpo com foco em conteúdo visual
- 📱 Layout totalmente responsivo
- 🌍 Perfil pessoal de viajante com galeria de fotos
- ✨ Tipografia cuidadosa com Google Fonts (Poppins)

---

## 🎨 Design e Estilo

**Paleta de Cores:**

- `#EF5F4C` - Cor de marca (laranja/vermelho)
- `#FFFFFF` - Cor de fundo (branco)
- `#F5F5F5` - Cor de superfície (cinza claro)
- `#313131` - Texto primário (cinza escuro)
- `#6C6C6C` - Texto secundário (cinza médio)

**Tipografia:**

- Fonte Principal: Poppins (Google Fonts)
- Hierarquia Visual: Títulos em 32px, texto padrão em 16px
- Peso de fonte: Regular (400) e Bold (700)

---

## 🔥 Destaques Técnicos

- **CSS Variables:** Sistema organizado de cores e tipografia através da pseudo-classe `:root`
- **Google Fonts:** Integração com fonte Poppins para estética moderna
- **Componentização CSS:** Estilos separados por componentes (nav, header, main, footer)
- **Flexbox:** Uso extensivo de flexbox para layouts
- **Object-fit:** Propriedade para tratamento adequado de imagens
